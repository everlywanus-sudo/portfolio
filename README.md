# Everly Wan — Engineering Portfolio

A responsive, single-page portfolio website based on `Engineering_Portfolio_Everly_Wan.pdf`.

## Preview
Open `index.html` in any browser. No installation or build tools required.

## Publish for free with GitHub Pages
1. Create a public repository (for example, `portfolio`).
2. Upload `index.html` to the repository root.
3. Open repository **Settings → Pages**.
4. Select **Deploy from a branch**, `main`, and `/ (root)`; save.
5. GitHub Pages will show the published site address after deployment.

## Customize
- Change the introduction and project details in `index.html`.
- Replace email, LinkedIn, and repository URLs if needed.
- Add screenshots later when you have them; the source PDF did not contain project imagery.
- Confirm the contact email before publishing. The source PDF lists `everly.wan.us@gmail.com`, which differs from an earlier resume.

This site does not claim unfinished projects as completed and distinguishes developing skills from used tools.
